01 / THE SERVICE

एक prompt से एक शुरुआती टूल।

Nischay Forge AI prompt को classify करता है: सामान्य बातचीत पर chat response और स्पष्ट utility/tool request पर generated HTML mini-app देता है। सेवा “जैसी है” और “जैसी उपलब्ध है” आधार पर प्रदान की जाती है; output आपके उद्देश्य के लिए सही, पूरा या उपयुक्त होगा इसकी गारंटी नहीं है।

02 / AI-GENERATED CODE

AI output को भरोसे से पहले परखें।

टूल AI से स्वतः तैयार होते हैं और इनमें तथ्यात्मक, गणितीय, कार्यात्मक, accessibility या सुरक्षा संबंधी गलती हो सकती है। किसी output को production, वित्तीय, कानूनी, स्वास्थ्य, सुरक्षा-महत्वपूर्ण या अन्य उच्च-जोखिम निर्णयों में उपयोग न करें, जब तक योग्य व्यक्ति उसे स्वतंत्र रूप से जाँच और सत्यापित न करे। Generated code पेशेवर सलाह या audited software का विकल्प नहीं है।

प्रीव्यू sandbox और network policy जोखिम घटाने में मदद करते हैं, लेकिन हर browser और downloaded file की सभी जोखिम स्थितियों को समाप्त करने की गारंटी नहीं देते। डाउनलोड की हुई फ़ाइल चलाने से पहले उसे स्वयं पढ़ें और अपने डिवाइस पर लागू सुरक्षा उपाय रखें।

महत्वपूर्ण: generated calculator या converter का नतीजा निर्णय का अकेला आधार न बनाएं।

03 / RESPONSIBLE USE

सेवा का इस्तेमाल समझदारी से करें।

आप सहमत हैं कि आप सेवा का उपयोग केवल वैध उद्देश्यों के लिए करेंगे; नुकसान पहुँचाने वाला, छलपूर्ण, गैरकानूनी या दूसरों के अधिकारों का उल्लंघन करने वाला tool request नहीं देंगे; सुरक्षा नियंत्रणों को bypass करने, अनधिकृत डेटा जुटाने या network access कराने की कोशिश नहीं करेंगे; और अपने prompt में ऐसा व्यक्तिगत/गोपनीय डेटा नहीं देंगे जिसे AI provider को भेजना उचित न हो।

04 / YOUR SAVED TOOLS

सेव और डाउनलोड आपके नियंत्रण में।

लाइब्रेरी आपके browser के localStorage में रहती है। आप सेव किए गए tools चलाने या हटाने के ज़िम्मेदार हैं। डाउनलोड की गई standalone HTML फ़ाइल आपके डिवाइस पर चली जाती है और browser में चल सकती है; डाउनलोड/चलाने के निर्णय और उस फ़ाइल को सुरक्षित रखने की ज़िम्मेदारी आपकी है।

05 / AVAILABILITY & CHANGES

AI और browser सेवाओं पर निर्भरता।

Tool generation बाहरी AI provider की उपलब्धता, model access और network पर निर्भर करता है। primary model न मिलने पर ऐप configured fallback का प्रयास करता है; दोनों अनुपलब्ध होने पर generation पूरी नहीं हो सकती। Browser speech recognition, PWA installation और offline caching की उपलब्धता device/browser के अनुसार बदल सकती है। हम सेवा या इन सुविधाओं की uninterrupted उपलब्धता का वादा नहीं करते।

इस सेवा का उपयोग करके आप समझते हैं कि AI-generated output को जाँचना आवश्यक है और सेवा का उपयोग आपके अपने विवेक व जोखिम पर है।
