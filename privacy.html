01 / MICROPHONE

माइक आपका है।

वॉइस इनपुट Web Speech API के ज़रिए चलता है। माइक तभी अनुरोध किया जाता है जब आप स्पष्ट रूप से वॉइस बटन टैप करें। आप ब्राउज़र की permission कभी भी अस्वीकार कर सकते हैं; लिखकर टूल बनाना तब भी उपलब्ध रहता है। रिकॉर्डिंग चल रही हो तो स्क्रीन पर माइक की सक्रिय स्थिति और ऑडियो वेव संकेत दिखता है। रोकने के लिए बटन दोबारा दबाएँ या ब्राउज़र permission बंद करें।

02 / AUDIO HANDLING

हम ऑडियो फ़ाइल रिकॉर्ड या सेव नहीं करते।

Nischay Forge ऐप ऑडियो रिकॉर्डिंग फ़ाइल नहीं बनाता, अपलोड नहीं करता और अपने सर्वर पर आवाज़ स्टोर नहीं करता। वॉइस recognition browser के speech service से होती है। आपके ब्राउज़र, operating system या चुने गए speech provider के अनुसार आवाज़ की प्रोसेसिंग डिवाइस पर या उनके सर्वर पर हो सकती है; यह प्रक्रिया उनके privacy controls और शर्तों के अधीन है, जिसे हम नियंत्रित नहीं करते। यदि आप उस प्रोसेसिंग से सहज नहीं हैं, तो टेक्स्ट इनपुट का उपयोग करें।

पहचाना गया टेक्स्ट प्रॉम्प्ट आपके अनुरोध पर AI टूल बनाने के लिए सर्वर को भेजा जाता है। ऐप recognition की मूल audio stream को संग्रहित नहीं करता।

03 / PROMPTS & AI

आपका प्रॉम्प्ट, आपके अनुरोध के लिए।

जब आप “बनाइए” दबाते हैं, आपका टेक्स्ट प्रॉम्प्ट सुरक्षित server endpoint से चुने गए AI model provider तक जाता है ताकि वह जवाब या HTML टूल तैयार कर सके। इस ऐप की सेवा के लिए prompt और generated response अस्थायी रूप से अनुरोध में उपयोग होते हैं; Nischay Forge की ओर से कोई user account या server-side prompt history नहीं बनाई जाती। चुने गए provider की अपनी retention और privacy नीति लागू हो सकती है। संवेदनशील, वित्तीय, स्वास्थ्य या पहचान संबंधी जानकारी prompt में न डालें।

Google Gemini API key केवल सर्वर पर protected setting में रखी जाती है; वह आपके ब्राउज़र, downloaded tool या public source files में शामिल नहीं होती।

04 / LOCAL DATA

आपकी लाइब्रेरी इसी डिवाइस पर।

सेव किए गए टूल और उनकी HTML सामग्री आपके ब्राउज़र के localStorage में इसी डिवाइस पर रखी जाती है। Nischay Forge सर्वर पर library sync नहीं होती। ब्राउज़र डेटा मिटाने, private browsing या storage साफ़ करने से सेव किए गए टूल हट सकते हैं। ब्राउज़र/डिवाइस बदलने पर वे अपने-आप स्थानांतरित नहीं होते—ज़रूरी टूल की डाउनलोड की हुई HTML फ़ाइल अलग से सुरक्षित रखें।

05 / GENERATED TOOLS

टूल एक अलग sandbox में चलता है।

AI से बना HTML इस ऐप के iframe में सीमित sandbox permissions के साथ चलता है। प्रीव्यू के लिए tool document को अलग data URL origin में खोलते हैं और network connections को CSP से रोकते हैं। जनरेटेड tool आपके prompt की सामग्री पर निर्भर करता है; उसमें त्रुटियाँ संभव हैं। डाउनलोड की गई standalone HTML फ़ाइल पर आपके डिवाइस के browser की सुरक्षा लागू होती है—केवल भरोसेमंद output डाउनलोड और चलाएँ।

06 / YOUR CHOICES

आप तय करें कि क्या साझा करना है।

वॉइस की जगह टेक्स्ट इस्तेमाल करें, mic permission बंद करें, केवल ज़रूरी prompt भेजें और अपनी library/browser storage कभी भी मिटाएँ। यह नीति बताती है कि ऐप कैसे बनाया गया है; browser और बाहरी AI provider की अपनी सेवाओं और नीतियों पर उनका नियंत्रण रहता है।
